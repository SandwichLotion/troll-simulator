    Custom username sheet

    Upload a CSV with the columns username,type,bio. Type is good, bad or any (the default). Bio is optional.

    Soundbytes

    Upload a CSV with the columns difficulty,Text They Say,mp3file. Difficulty is easy, medium, hard or all. The mp3 plays when a guest says that exact text. Repeat a line with different mp3 files to have one picked at random. Lines that aren’t built into the game are added as new things guests can say.

    Soundbyte grid

    Load a soundbytes CSV to see its lines here.

    Drag and drop mp3 files here. Files are matched to lines by file name. Drop a file on a line’s mp3 box to link it to that line, or select the box to choose one.

    Clip limits

    The largest and longest allowed mp3 clip come from a text file named config.txt (max_clip_kb and max_clip_seconds).
